# King's Reset

A small, mobile-first personal planner for training, skincare, haircare and progress tracking.

## What's included
- Today view with daily tasks and completion progress
- Weekly calendar with selectable days
- Four beginner-friendly workout sessions (Saturday is optional)
- Skincare and haircare routine notes
- Weekly consistency chart and simple strength log
- Local browser storage and JSON data export
- Installable PWA files for HTTPS hosting

## Put it online
1. Create a new GitHub repository (or a folder in a repository).
2. Upload `index.html`, `manifest.json`, and `sw.js` to the repository root.
3. Enable GitHub Pages in repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Open the HTTPS GitHub Pages URL in Safari on your iPhone.
5. Tap Share → Add to Home Screen → Add.

## Important
- This version stores data in the browser on the device. It does not sync between devices.
- Export your data from the Progress tab for a backup.
- The AI coach is not connected in this static version; you can bring your progress notes back to ChatGPT to adjust the plan.
- The training plan is a conservative starting template. Use comfortable technique, start light, and ask a qualified instructor for help with unfamiliar gym movements.
